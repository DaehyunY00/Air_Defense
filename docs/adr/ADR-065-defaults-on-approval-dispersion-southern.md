# ADR-065 — 승인 계선·표적 산포·남부 축선을 기본값으로 전환

> 본 문서의 모든 수치는 공개자료 기반 **정책연구용 개념값**이며 실제 작전자료가 아니다.

## 맥락

ADR-058(승인 계선)·063(표적 산포)·064(남부 축선)는 불변 규칙 1("신규 거동은 플래그 뒤, 기본
OFF")에 따라 전부 기본 OFF였다. 그 규칙의 목적은 **편향 귀속과 감사 추적**이지 "영원히 OFF"가
아니며, 세 ADR 모두 "기본 ON 전환은 별도 판단 사안"으로 남겨 두었다.

기본 OFF를 유지한 결과 **기본 실행이 모델을 잘못 대표**하고 있었다:

| 플래그 OFF의 결과 | 왜 문제인가 |
|---|---|
| As-Is 승인 대기·협조몫이 **항상 0** | 이 연구의 핵심 결론 G6①("As-Is 병목 = 협조·승인")과 **정반대 그림**. KJADS 문제 정의(각 군 개별 작전 → 음성 VTC 의존) 자체가 미모델링 상태 |
| 같은 축선의 모든 위협이 **좌표 한 점**으로 수렴 | seed를 바꿔도 착탄점이 불변. 어떤 해석으로도 정당화 불가 |
| 표적 회랑이 3권역뿐 | FULL 배치 84문 중 **남부 14문이 어떤 seed에서도 교전 기회 없음** |

사용자 결정(2026-07-28): **셋 다 기본 ON**.

## 결정

`approvalChain` · `threatTargetDispersion` · `southernAxes` → **기본 ON**. 명시적 `false`(딥링크
`appr=0`·`disp=0`·`south=0`, UI 체크 해제)로 끌 수 있어 반증·감사 경로는 유지된다.
반증 전용 `approvalChainTobe`·`nativeWtaCostAsis`는 **기본 OFF 유지**(반사실 실험 도구).

### 함께 바꿔야 했던 것 — 어댑터 판정 (놓쳤다면 조용한 불일치)

카탈로그 변형 선택이 `features.approvalChain === true`였다. 엔진 기본값만 뒤집으면 **features에
키가 없는 호출에서 엔진은 승인 계선 ON인데 카탈로그에는 coord 링크가 없는** 상태가 된다 —
오류 없이 "승인 계선을 켰는데 협조 홉이 0"인 결과가 나온다. `!== false`로 바꿔 엔진 기본값과
정합시켰다(`southernAxes`도 동일).

### features 노출 방식 변경

종전 "ON일 때만 노출"(OFF wire shape 보존)에서 **항상 실제 해석값 신고**로 바꿨다. 소비 측
(분석 탭의 "미측정" 표기 — ADR-062)이 실행 조건을 정확히 읽어야 하기 때문이다.

## 편향 원장 (paired 20 seed × 900초 × ×1.5 · LEGACY_NORMAL)

| 셀 | 격추율 Δ(To-Be−As-Is) | 결심지연 Δ | As-Is 협조몫 | exchangeSat As-Is/To-Be |
|---|---|---|---|---|
| SC1 구 기본(전 OFF) | −0.5pp ±1.9 (n.s.) | −21.9s ±2.9 | **0.0s** | 21.25 / 21.88 |
| SC1 신 기본(3종 ON) | **+2.9pp ±2.7 (유의)** | **−33.7s ±2.8** | **34.1s** | 20.00 / 20.42 |
| SC3 구 기본(전 OFF) | +38.7pp ±1.5 | −68.0s ±3.9 | **0.0s** | 6.55 / 4.57 |
| SC3 신 기본(3종 ON) | +39.9pp ±1.5 | **−82.2s ±7.6** | **23.3s** | **25.51** / 4.59 |

### 🔴 개선폭 20% 이상 이동 공지

**결심지연 개선폭이 SC1 +54%(−21.9→−33.7초), SC3 +21%(−68.0→−82.2초) 커졌다.**

해석에 주의가 필요하다 — **To-Be가 좋아진 것이 아니라 As-Is가 원래 치러야 할 비용을 이제
치르는 것**이다. 근거: As-Is 협조몫이 0.0초 → 23~34초로 발현했고, To-Be 쪽 절대값은 거의
움직이지 않는다. 종전 기본값은 As-Is를 **실제보다 유리하게** 모델링하고 있었고, 그만큼
To-Be 개선폭을 과소평가하고 있었다(ADR-057의 "낡은 기준선이 효과를 부풀린다"와 반대 방향).

SC1 격추율 Δ는 **부호가 바뀌고 유의해졌다**(−0.5pp n.s. → +2.9pp 유의). 저부하 시나리오에서
승인 지연이 실제로 격추 결과를 가르기 시작했다는 뜻이다.

**SC3 As-Is exchangeSat 6.55 → 25.51 (3.9배)**: 남부 축선 추가로 As-Is가 남부 위협을 놓쳐
격추 위협가치(분모)가 줄어든 결과다(To-Be는 4.57→4.59 불변). exchangeSat의 알려진 함정
("못 잡으면 분모가 준다" — `docs/params.md` 비고)이 그대로 드러난 사례이므로 **방어효율·격추율과
함께 읽어야 한다**.

## 두 가지 보증 약화 (정직 기록)

### 1. ADR-056 지문 재기준화

`tests/engagement-state-unification.test.mjs`의 4케이스 SHA는 "unifiedEngagementState OFF ==
**ADR-056 도입 전**"을 증명하던 지문이었다. 기본값 전환으로 배경이 바뀌어 그 비교는 **재현
불가**가 되었다. 지문을 신 기본값으로 재기준화했고, 어서션의 의미는 **"OFF == 현행 기준선"**
(이후 회귀 방지선)으로 약해진다. 구 지문은 git 이력에 있다. `tests/hires-baseline.json`도 같은
이유로 재수립했다(구 기준선 폐기 사유를 파일 note에 기록).

### 2. ADR-059 반증 레버의 개입 빈도 감소

`nativeWtaCostAsis`(As-Is 비용항 반증)가 무는 셀이 **6셀 중 2셀**로 줄었다(구 기본값에서는
FULL·SC3·300초 셀에서 보존율 0.686→0.678·격추율 0.583→0.500로 발화했으나, 신 기본값 같은
셀은 **완전 무효과**). 어서션을 실제로 발화하는 셀(FULL·SC3·×3·600초)로 옮기고, **발화하지
않는 셀(×1.5)도 함께 어서션으로 고정**해 빈도 감소 자체를 증거로 남겼다. 이 변화는 ADR-059의
원 결론("비용항은 거의 물지 않는다 — 절약은 교전량·기하에서 나온다")을 **오히려 강화**한다.

## G6 재산출 (신 기본값)

① **As-Is 핵심 병목 = 협조·승인** — **유지·강화**. 종전에는 협조몫이 0으로 표시돼 이 결론을
   기본 화면에서 확인할 수 없었으나, 이제 23~34초로 직접 관측된다.
② **To-Be 병목 → 무기체계** — 유지(To-Be 결심지연·exchangeSat 절대값이 거의 불변, 잔여 누수는
   교전 능력 쪽).
③ **exchangeSat ≫1** — 유지. 전 셀 4.59~25.51로 오히려 As-Is 비대칭이 심화됐다.
④ **신궁·천마 탄도탄 불가** — 유지(`constraints.test.mjs`·`southern-axes.test.mjs` 어서션).
**뒤집힌 결론 없음.**

## 되돌리는 법

- 런타임: 딥링크 `appr=0&disp=0&south=0` 또는 UI 체크 해제 — 구 기본값 실행을 그대로 재현한다.
- 코드: 이 커밋 revert(플래그 자체는 남아 있으므로 기본값만 되돌리면 된다).

## 한계

1. **세 변경을 동시에 전환** — 편향 원장은 "3종 묶음"의 합산 효과만 보여준다. 개별 효과는 각
   ADR(058·063·064)의 단독 측정에 남아 있으나, **상호작용은 미측정**이다.
2. **문서 수치의 이중 기준** — `docs/실험보고서.html`의 기존 표는 구 기본값(전 OFF)에서 측정된
   값이다. 지우지 않고 조건을 명시했으나, 신 기본값 전면 재측정은 후속 과제다.
3. **SC3 정체성 변경** — 남부 축선이 기본이 되면서 SC3는 "KJADS 문제 상황 3 원문 + 남부 종심
   확장(ADR-064)"이다. `basis` 선언에 명시했다.
