저장소 루트의 `K-JAMDS_분석_방법과_결과.pdf`를 만드는 재현 소스다. 종전에는 이 문서와

본문은 SC3만 다룬다. SC1·SC2는 3-3절의 단일 seed 참고 표로만 남긴다.

**관측 시간은 화면 기본값인 1800초다(ADR-101).** 러너는 기본값을 화면에서 직접 읽으며, 600초로
고정돼 있던 C2 기록 실행도 기본값을 따른다. 600초판의 요약(`previous-600s-summary.json`: 네 기준 실행,
20쌍 통계, 누수 원인)을 보존해 3-2절과 6절에서 비교한다. 생성기는 600초판의 엔진·어댑터 해시와
seed 집합이 현재와 같은지 검사한다.
과거 2026-09-10/11 보고서는 당시 소스·원시 결과로 보존한다. xlsx는 코드에서 내보낸 참조표이며,
어느 러너도 xlsx 값을 입력하지 않는다.

## 입력과 재현

`report-common.mjs`는 지휘흐름 HTML의 `PARAMS`, `parseCommandFlowParams`, `features()`를 격리된
VM에서 직접 실행한다. 숫자 기본값을 독자적으로 복사하지 않는다. `par=true`가 실제 카탈로그에
전달되는 조건이다. 본 앱의 기본 설정과 지휘흐름 화면의 기본 설정은 구분한다.

두 JSON에는 분석 당시 HEAD와 엔진·카탈로그 어댑터·프로토타입 SHA-256, 모든 플래그, 실행 시각을
저장한다. `report-gen.mjs`는 HTML을 쓰기 전에 다음을 검사하고, 하나라도 어긋나면 멈춘다.

- 두 JSON의 소스 커밋과 세 파일의 SHA-256이 서로 같다.
- 네 기준 실행(2배치 × 2구조)의 생성·격추·누수·미해결·발사 횟수가 두 JSON에서 같다.
- 엔진의 시간 표본 수가 발사 항적 수와 같다. 계보 재구성에서 빠진 발사(명령 계보가 없는 자위권 발사)의
  수는 기록된 제외 사유의 합과 같고, 빠진 것이 없는 실행은 탐지→최초 발사 평균도 같다.

```bash
D=docs/analysis/2026-09-19-current-reports
node $D/analysis-run.mjs $D/analysis-out.json --workers 2
node $D/c2-analysis-run.mjs --self-test
node $D/c2-analysis-run.mjs
node $D/report-gen.mjs
node $D/render-reports.mjs
node $D/verify-pdfs.mjs /tmp/kjamds-pdf-qa
```

일반 분석은 **182개 셀 + 별도 탐침 1개**다. 기준선 12 + OAT 64(16조건) + seed 반복 80 + 강도 20 +
관측창 6이다. C2 기록 실행 4개는 별도다. 계산 worker는 최대 2개로 제한한다(러너가 3 이상을 거부한다).

`render-reports.mjs`는 설치된 Playwright와 Chrome을 사용한다. 필요하면 `PLAYWRIGHT_MODULE_DIR`와
`CHROME_PATH`를 지정한다. 글꼴 로딩·페이지 가로 넘침·본문/꼬리말 겹침을 검사하고, 겹치면 인쇄하지
않는다. `verify-pdfs.mjs`는 기대 쪽수를 `render-qa.json`에서 읽어 Poppler로 쪽수·본문·꼬리말을
검사하고 전 페이지를 PNG로 렌더링한다.

## 이번 실행의 검증 범위

- 소스 `3874d4c`에서 일반 분석 182셀과 탐침 1개, C2 기록 4개를 1800초로 새로 실행했다
  (분석 셀 1,594.946초). 엔진과 카탈로그 어댑터의 해시는 600초판(`d398215`)과 같다 —
  **수치 변화는 관측 시간에서만 온다.**
- 모든 셀의 생성/격추/누수/미해결 보존식과 누수 원인 합계, 20쌍 seed의 생성 수를 검사했다.
- C2 네 실행은 항적 기록 각각 228/228개이며 trace/flow/C2 기록 상한에 걸리지 않았다.
  실제 발사 항적 89/105/176/187개, 합계 557개 중 555개의 최초 발사 시간 계보를 연결했다.
  나머지 2개는 명령 계보가 없는 자위권 발사다.
- 통합 PDF 20쪽의 DOM 배치 검사와 Poppler 텍스트·PNG 검사를 통과했다. 시각 검토의 범위는
  `QA.md`에 적는다.

이 범위는 보고서의 재현·집계·표현을 검증한다. 실제 군사 운용 성능을 검증한 것으로 해석하지 않는다.
전체 회귀 스위트 52개는 같은 날 `556ed69`(엔진 동일)에서 통과했고, 이번 문서 작업 때문에 다시 돌리지는
않았다.

## 해석 규칙

- 전체 생성 = 격추 + 확정 누수 + 종료 미해결. 1800초 종료 시점에도 10~15%가 미해결이며 최종 생애 성능이 아니다.
- 20개 seed에서 같은 seed끼리 차이를 먼저 구한다. 평균 차이의 95% CI는 Student t(19)를 사용한다.
  단일 seed OAT에는 신뢰구간을 부여하지 않으며 다중 비교 보정도 하지 않았다.
- 엔진의 `timeToEngage`와 `decisionDelay`는 성공한 `_onIadsFire`에서 수집한다. 각각 생성/탐지에서
  최초 실제 발사까지의 값이다. 결과 필드의 과거 주석을 그대로 인용하지 않는다.
- 역할 관계(그래프의 회색 점선)와 후보 근거는 실제 통신·명령 사건이 아니다. 관측되지 않은 노드·경유를
  추가하지 않는다.
- 도메인 제대의 통보 큐는 IAOC 결심을 차단하지 않는다. 결정권·승인·거부권의 실증으로 해석하지 않는다.
- 보고서는 개념 모델의 재현·기록 정합성 분석이며 군사 운용 검증이나 현실의 전술 최적화 권고가 아니다.
