①
탐지·인지
탐지 레이더(그린파인·FPS-117·TPS-880K)가 책임 지휘소에 보고. 감시 등급 항적만 — 이것만으로는 발사 불가
②
대기 지시(준비)
탄도탄·방사포에 한해 요격 창이 있는 상층 포대 전부에 「준비하라」. 표적 정보만 주는 준비 지시 — 발사 권한 아님
③
사수 지정(결심)
항적 접수 직후 포대마다 「지금/언제 쏠 수 있나」 예측(4초 주기 상태 보고 + 계선 지연). 미군과 협조(As-Is 음성 20초 · To-Be 데이터링크 1초) → 「준비되면 쏘라」 명령
④
사격통제 · 발사 · 보고
포대 레이더 탐지→추적→사격통제 등급, 요격점이 사거리·고도 안에 들면 발사. 결과 보고(BDA) — 빗나가면 지휘소가 재지정
⑤
수행 불가 · 재지정
예측 준비 시각 + 30초가 지나도 못 쏘면 포대가 CANTCO 회신, 지휘소가 1초 뒤 다른 사수 지정(seed 29 · As-Is 70건 · To-Be 37건)
예외 — 자위권 발사 ③ 사수 지정을 받지 못한 포대가 발사 마감이 닥친 위협에 「내가 맞을 것 같다」고 자체 판단해 쏜다(명령 없음). seed 29에서 자위권 결심 As-Is 10건 · To-Be 11건 중 실제 발사 1·2건, 나머지는 발사 직전 재검증에서 발사 불가. 화면에서는 붉은 점선 고리 + 「자위권 ③」 표식.
5판에서 바뀐 것 4판까지는 ②의 대기 지시가 발사 권한을 겸해 포대가 조건이 갖춰지면 명령 없이 쏘는 「긴급발사」가 방사포의 5분의 4였다. 표준 절차(C2 명령 → 포대 요격 → 결과 보고)로 고치자 명령 경로의 차이가 그대로 드러나, 비슷하던 격추 수(211 대 205)가 176 대 194로 갈라졌다. 6판은 공중 위협의 생성 기준까지 탄도와 같게(발사·이륙 원점) 맞춘 조건이며 178 대 192다.
