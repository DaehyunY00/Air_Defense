# ADR-080 — 국지레이더의 MCRC 직보를 걷어내고, 균등분포를 정규분포로 바꾼다

- 상태: 채택
- 일자: 2026-08-01
- 관련: ADR-051(군단 AOC C2A) · ADR-058(승인 계선) · ADR-078(조율층) · ADR-079(문자 항적 중계)

## 결정 ① — As-Is 국지레이더(TPS880K) → MCRC 직접 보고 제거

### 배경

ADR-079 검토 중 사용자 질문("ADC2A가 받는 국지레이더·MFR 항적은 MCRC에 어떻게 공유되나")으로 드러난 숨은 가정: 모델은 **국지방공레이더 8대 전부가 공군 MCRC로 4초 주기 자동 보고**하도록 배선돼 있었다. 그래서 MCRC는 ADC2A의 공유 없이도 국지 그림을 언제나 봤다.

TPS880K는 육군 자산이다. 공군 MCRC로의 직접 데이터링크 보고는 공개근거가 없고, **2022-12-26 무인기 사건의 공식 교훈**(1군단 국지레이더가 최초 포착했으나 상황 전파 지연 — 합참 전비태세검열 지적)과 정면으로 어긋난다. 그 직보가 있는 한 "육군이 본 것을 공군이 제때 못 봄"이라는 실증된 실패 모드가 **모델에서 구조적으로 발생 불가능**했다 — As-Is에 유리한 숨은 가정이었다.

### 새 배선 (As-Is)

```
국지레이더(TPS880K) ── 4초 자동 ──▶ 관할 방공C2A ── 문자 45초 ──▶ MCRC
                                     (corps_aoc_track_share · C2-CHAT-TRACK-01 상행)
```

- 편제 소속 2대(1군단·수방사 선언분)는 종전대로 양 모드 보고 유지.
- 비편제 6대(legacy 이식 산물)는 **최근접 방공C2A**로 As-Is 전용 보고(개념 배정). To-Be에 새 링크를 깔지 않는 이유: To-Be는 IAOC 직결로 이미 같은 그림을 보고, 새 링크는 To-Be를 움직여 변경 서명을 흐린다.
- 방공C2A → MCRC 상행 문자 전파(`corps_aoc_track_share`) 신설 — ADR-079 하행 문자와 같은 매체·같은 파라미터(C2-CHAT-TRACK-01, 적용범위를 양방향으로 확장).
- **To-Be 측 직결(통합망 배포)은 그대로다.**

이로써 2022 실패 모드가 모델에 존재하게 된다: As-Is에서 MCRC가 국지 항적을 보는 최단 경로는 4+45초(문자 전파) 또는 주축 MFR 중계(3초, MFR이 보는 표적만)다.

## 결정 ② — 균등분포 → 정규분포

카탈로그에서 균등분포는 음성 협조(C2-VOICE-COORD-01, Uniform 10~30) 하나였다. **Normal(평균 20, σ5)**로 교체 — ±2σ가 종전 구간과 일치하고, 절차 지연은 구간 내 균일보다 대표값 부근에 몰리는 것이 자연스럽다. 음수 꼬리는 엔진 `_linkDelay`의 `Math.max(0,·)`가 절단한다. 엔진 샘플러는 `normal`을 이미 지원해 코드 변경이 없다.

## 결과 — 열한 번째 재기준선

**As-Is 3케이스만 이동, To-Be 3케이스 bit-exact 불변** — 두 결정 모두 As-Is 전용 계선·분포만 건드리므로 정확히 그래야 하며, 실측으로 확인했다(ADR-079와 같은 서명).

| 케이스 | 격추 (ADR-079 → 080) |
|---|---|
| sc1\|asis | 25 → 22 |
| sc2\|asis | 12 → 13 |
| sc3\|asis | 57 → 64 |
| To-Be 3케이스 | **불변** (25 · 13 · 114) |

단일 seed 방향은 요동이므로(sc3이 오히려 상승) 12 seed 쌍체로 재확인했다:

| | As-Is 격추 | 쌍체 Δ(To-Be−As-Is) 95% CI |
|---|---|---|
| SC3 (ADR-079 시점) | 65.3 ± 2.4 | 36.2 [31.3, 41.0] |
| **SC3 (ADR-080)** | **61.8 ± 2.3** | **39.7 [34.7, 44.6]** |
| SC2 (ADR-080) | 13.0 ± 0.5 | **−0.2 [−0.4, 0.1]** — 동률 |

- SC3: As-Is가 ~3.5 감소, Δ가 그만큼 확대 — **To-Be 유리 방향**이다. 국지 그림이 문자로 늦게 전파되는 예상된 효과이고, 실증된 실패 모드를 모델에 넣은 대가이므로 정당하다. 다만 인용 시 이 ADR의 근거(2022 사건·자산 소속)를 함께 밝혀야 한다.
- SC2(무인기): **놀랍게도 동률.** 무인기 대응은 국지축(자기 레이더 2~4초)과 주축 MFR 중계(3초)가 지배해서, MCRC의 국지 그림 지연이 결과에 안 닿는다. 즉 이 변경으로 2022 실패 모드가 "구조적으로 가능"해졌지만 LEGACY 배치의 수치 재현까지 가는 것은 아니다 — MFR 커버리지 밖 원거리 무인기 시나리오가 있어야 드러난다(후속 과제).

### 파생 관측 — shadow-eval 어서션 교체

「선택 손실이 LOCAL_AD 축에 집중된다」(ADR-074 관측)가 이 셀에서 무너졌다 — 국지 그림의 MCRC 유래 출처가 늦어지자 LOCAL_AD의 regret 표본이 8건으로 줄고 전부 최적이 됐다(100% vs 주축 95.2%). 표본 축소 자체가 새 관측이므로 어서션을 「LOCAL_AD 표본이 주축의 1/5 이하로 희소 — 늦은 상황그림이 국지축 결심 기회를 잠식」으로 교체했다.

### native-wta 반증 셀 — 이번에는 이동 없음

24셀 재실측: 8/24 발화(4242×{1,1.5} · 777×1.5 · 12345×3). **어서션 셀(×1.0·4242)과 정직 관측 셀 2개가 전부 그대로 유효** — ADR-065 이후 처음으로 셀 이동이 없는 판이다.
