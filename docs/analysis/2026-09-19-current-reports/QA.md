  두 JSON의 `meta`를 뺀 본문이 직전 실행과 같음을 확인했다(엔진 불변 · 화면 표시만 변경).

  통신 상태와 정식 노드 필터.
- `report-gen.mjs`의 교차 검산 통과: 소스 해시 일치, 네 기준 실행의 계정 일치, 시간 평균 일치.

- Poppler 110 dpi PNG 20쪽을 모두 열어 제목·표·한글·카드·화살표·주석·꼬리말의 잘림/겹침을 확인했다.

## 증거와 재현

`pdf-qa.json`에 최종 PDF SHA-256, 페이지별 텍스트 길이, PNG 경로와 SHA-256을 보존한다.
임시 이미지·추출 텍스트·pdfinfo는 `/tmp/kjamds-pdf-qa/`에 있으며 Git 산출물이 아니다.

