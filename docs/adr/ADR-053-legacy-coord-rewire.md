# ADR-053 — Legacy 세트 상향 협조 재배선 (ICC↔MCRC 직접 음성 폐기)

## 상태

채택 — 2026-07-27. ADR-052의 "ICC↔MCRC 음성/VTC 협조" 부분을 대체한다.

## 맥락

ADR-052는 legacy 10세트 전부의 ICC를 MCRC와 음성/VTC(당시 180초, 이후 10~30초 실험값)로
직결했다. 사용자 사실검증 요청으로 공개자료를 확인한 결과 이 직결 음성 링크는 근거가 없었다:

- **ICC/ECS는 천궁 계열 편제 용어이고 그 체인은 데이터링크다.** 공개자료상
  KAMD작전센터→대대 작전통제소(ICC)→포대 교전통제소(ECS)로 실시간 전달되며, 천궁 블록II
  작전통제소는 Link-16·ATDL-1·MDIL 연동을 지원한다(나무위키 천궁-II 항목, 아시아경제
  2024-08-12). 천궁·패트리엇은 **공군 방공유도탄사령부** 소속 — MCRC와 같은 군 계선이라
  음성협조 대상이 아니다.
- **육군 저고도 방공(천마·비호) 계선 내부는 ADC2A/KVMF 데이터링크다.** 방공지휘통제경보체계가
  군단/사단 방공레이더·무기·작전통제소를 KVMF 표준 메시지로 연결한다(국방과학연구소,
  보안뉴스 2016-08). 
- **음성/유선이 실증된 경계는 육군 군단 ↔ 공군작전사(MCRC)다.** ADC2A와 공군 MCRC·KAMD
  작전센터는 데이터링크 미연동으로 운용되며(공개 보도), 2022-12-26 무인기 사건에서 1군단이
  국지방공레이더 항적을 공작사에 **유선전화**로 전파했고 고속상황전파체계·방공고속지령대는
  사용되지 않았다(한국일보 2023-01-25, 연합/다음 2023-01-26).

## 결정

- **천마(육군) 5세트 (W1, W3, C1, C3, E2)**: ICC↔MCRC 직접 링크 제거.
  `ICC-<key>↔AOC-1C`를 As-Is KVMF(30초)/To-Be 2초 데이터링크로 신설. 육↔공 교전협조는
  기존 `AOC-1C↔MCRC` 음성 링크(C2-VOICE-COORD-01, 10~30초 균등분포)로 수렴한다.
- **천궁-II(공군) 5세트 (W2, W4, C2, E1, E3)**: ICC↔MCRC를 As-Is Link-16(12초,
  C2-L16-UPD-01)/To-Be 2초 데이터링크로 변경. 음성 아님.
- ICC 노드의 service를 계선에 맞게 분리(천궁-II=af, 천마=army — ECS·MFR·포대와 일치).
- 신뢰도: 계선 구조는 B(2차 보도·공식 홍보자료), 지연 대표값은 기존 파라미터 승계(C).

## 결과·영향

- As-Is 음성협조 발화 지점이 27개 링크 → **기본 토폴로지의 육↔공 경계 7개 링크**로 수렴
  (AOC-1C↔MCRC, JAOC-CD↔MCRC, AOC-1C↔JAOC-CD, MCRC→KAMDOC). "육·공군 간 단절, 군 내부는
  연동"이라는 KJADS 문제상황 서사와 정확히 일치하게 된다.
- 천마 계통의 As-Is 협조 대표 경로는 ICC→AOC-1C(30)→MCRC(20) = 50초로 종전 직결
  음성(20초)보다 길어질 수 있으나, 매체는 사실에 부합한다(KVMF 데이터링크 + 군간 음성).
- 천궁-II 계통은 As-Is에서도 12초 데이터링크로 연동되어 중복교전 협조가 빨라진다.
- 결과 기준선(phase0-baseline·refine-snapshot·legacy-snapshot)은 의도적으로 재생성한다.

## 되돌리는 법

`js/data/links.js`의 legacy 세트 루프에서 weapon 분기를 제거하고 전 세트에
`{ icc↔MCRC, asis: VOICE_COORD, tobe: DL_FAST }` 쌍을 복원, `js/data/nodes.js`의 ICC
service를 'joint'로, 역할 문구를 원문으로 되돌린 뒤 기준선을 재생성한다.
