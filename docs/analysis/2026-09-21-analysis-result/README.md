## 조건을 나눈 기준 (3장)

원본의 16개 조건을 「지휘 구조·절차를 바꾸는가」와 「차이가 단일 실행의 잡음보다 큰가」로 나눴다.
잡음의 눈금은 같은 시작값끼리의 To-Be − As-Is 누수 차이가 20개 시작값에서 보인 표준편차(약 5~6개)다.

| 묶음 | 조건 (코드) | 처리 |
|---|---|---|
| 시나리오 가정 | 탄도 위협 출발점 연장(`lx`), 여러 지상 목적지 배정(`aim`) | 제외 — 위협의 경로를 바꾸는 조건 |
| 모델 세부 가정 | 처리시간 최솟값 적용(`floor`), 협조의 세부 처리 절차 생략(`pipe`) | 제외 — 지휘 대안이 아니고 차이가 작으며 배치·구조마다 방향이 엇갈림 |
| 지휘 절차·권한·정보 | `appr` `cop` `icc` `uavsd` `eor` `share` `sdf` `suit` `ew` | 주 표. 네 값이 모두 0인 행은 표에서 빼고 이름을 표 아래에 적음 |
| 시간 가정 | 포대통제 추가 처리시간(`ecs`), 명령을 내리는 작업 추가(`issue`), 통합 지휘소 판단시간 변경(`par`) | 「시간 가정에 얼마나 민감한가」 표로 분리 |

용어: `sdf`(`selfDefenseFire`, ADR-071·072)는 **자위권 사격**이다. `uavsd`(`uavLocalSelfEngage`, ADR-087)는 자위권이 아니라
국지방공이 소형 무인기를 상급 지휘소의 승인 없이 교전하게 하는 조건이라 「무인기 교전의 상급 승인 면제」로 적는다
(원본 PDF의 「무인기 자체 방어 사격 허용」은 자위권으로 읽혀서 바꿨다).

## 입력과 재현

| 파일 | 내용 |
|---|---|
| `../2026-09-21-sc3-final/summary-results.json` | 168개 조건의 집계. 표지·1~5장과 6장의 발사·중복·시간·비용 |
| `records-out.json` | 기준 4실행의 항적별 기록. 7장의 유형별 결과 |

`records-out.json`은 집계 JSON에 없는 항적별 기록을 얻으려고 기준 4실행을 다시 돌린 결과다.
`records-run.mjs`는 집계 JSON의 `meta.memoryPatches` 5개(생성 마감 1800초 · 모든 항적의 결과가 확정될 때까지 진행)를
**메모리에서만** 엔진에 적용한다. 저장소의 엔진 파일은 고치지 않는다. 각 패치 대상이 엔진 소스에 정확히 한 번
나오는지, 그리고 네 실행의 생성·격추·누수·발사·중복·발사 항적 수가 집계 JSON과 같은지 검사하고, 어긋나면 멈춘다.

```bash
D=docs/analysis/2026-09-21-analysis-result
node $D/records-run.mjs      # 약 70초
node $D/report-gen.mjs
node $D/render-report.mjs    # Playwright + Chrome
node $D/verify-pdf.mjs /tmp/kjamds-pdf-qa
```

`report-gen.mjs`가 HTML을 쓰기 전에 검사하는 것: 모든 조건에서 생성 = 격추 + 누수, 누수 사유 합계 = 누수,
항적별 기록의 항적 수·격추 수·발사 수·발사 항적 수 = 집계, 조건 목록이 예상한 12종(지휘 조건 9 + 시간 가정 3) + 제외 4종과 같음.
