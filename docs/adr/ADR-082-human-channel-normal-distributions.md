# ADR-082 — 육↔공 사람 매개 채널의 지연 분포를 정규분포로 통일한다

- 상태: 채택
- 일자: 2026-08-02
- 관련: ADR-058(승인 계선) · ADR-079(문자 항적 중계) · ADR-080(정규분포 전환·국지레이더 재배선) · ADR-081(KVMF 상급 경유)

## 배경

사용자 지적: **방공C2A(군단 AOC) → MCRC 교전현황이 90~180초 정규분포 형태가 더 맞지 않나.**
함께 문자 45초·음성 20초도 각각 30~60·10~30 정규분포로 정리하자는 요청.

확인해 보니 **음성 협조는 이미 `Normal(20, σ5)`** 였다(ADR-080). ±2σ가 10~30으로 요청과
정확히 같아 **변경할 것이 없다.** 남은 것은 교전현황 VTC와 문자 둘이다.

## 먼저 짚은 것 — 이건 형태 정리가 아니다

| 채널 | 종전 분포 | 최빈 | **평균** |
|---|---|---|---|
| 교전현황 VTC | Tri(90, 180, 270) | 180 | **180** (대칭) |
| 문자(서버 채팅) | Tri(20, 45, 120) | 45 | **61.7** (우편향) |

- **VTC**: 이미 180에서 뾰족한 단봉 분포다. 균등분포가 아니므로 "형태를 정규로"가 거동을
  크게 바꾸지 않는다. 실제 변경은 **범위를 90~270 → 90~180으로 좁혀 대표값이 180 → 135로
  25% 내려가는 것**이다.
- **문자**: 최빈값은 45로 같지만 오른쪽 꼬리가 120까지 길어 **평균이 61.7초**였다.
  `Normal(45, σ7.5)`로 바꾸면 평균이 **61.7 → 45초(−27%)** 로 내려간다.

즉 **둘 다 실질 변경**이며, 특히 VTC는 **이 채널만 유한 용량(1채널·4건)** 이라 지연이 곧
서비스율이고 드롭률로 증폭된다.

⚠️ **Triangular → Normal은 난수 소비 개수를 바꾼다**(삼각 1회 vs Box-Muller 2회+스페어).
모든 추출이 밀려 지문이 재배열되므로 **단일 seed 값을 방향 근거로 인용하면 안 된다**
(ADR-079의 비단조 실측과 같은 함정).

## 사전 등록한 채택 기준 (결과를 보기 전에 고정)

측정 셀: **SC3 · ×1.5 · 900초 · 12 seed 쌍체** (ADR-079와 같은 셀 — 그 표와 직접 비교 가능)

| 변형 | 문자 | 교전현황 VTC |
|---|---|---|
| BASE | Tri(20,45,120) 평균 61.7 | Tri(90,180,270) 평균 180 |
| V1 | Normal(45, σ7.5) | Tri 현행 |
| V2 | Normal(45, σ7.5) | Normal(180, σ45) — 대표값 유지 |
| V3 | Normal(45, σ7.5) | Normal(135, σ22.5) — 제안값 |

1. **서명(하드 체크)** — 세 채널 모두 As-Is 전용(To-Be 측 `comm = null`)이므로
   **To-Be는 bit-exact 불변**이어야 한다. 위반이면 채택 보류.
2. **방향 예측** — 지연이 줄므로 As-Is 격추 상승 · 중복교전 감소 · VTC 드롭 감소 →
   쌍체 Δ(To-Be−As-Is) 축소.
3. **VTC 선택 규칙** — V2와 V3의 쌍체 Δ가 **통계적으로 구분되지 않으면 V3 채택**하고
   "결론을 바꾸지 않음"을 근거로 기록. 구분되면 🔴 에스컬레이션 후 결정.
4. **크기** — Δ 상대 이동 ≥20%면 보고서 최상단 🔴.
5. 함께 관측 — `statusSharing` 전송/전달/드롭, 중복교전, 결심지연.

## 측정 결과

### 기준 ① 서명 — **완벽 충족**

To-Be 지문이 **4변형 전부 동일**하다.

| 케이스 | BASE | V1 | V2 | V3 |
|---|---|---|---|---|
| sc1\|tobe | `cb8200cef463` k=25 | 동일 | 동일 | 동일 |
| sc2\|tobe | `974828ff1cc2` k=13 | 동일 | 동일 | 동일 |
| sc3\|tobe | `7eb7184c5426` k=114 | 동일 | 동일 | 동일 |

기준선 6케이스에서도 To-Be 3케이스는 **지문·격추·누수·이벤트 수 전부 불변**이고,
`engagement-state`·`decision-audit`·`shadow-eval` 세 스위트의 To-Be 지문도 **글자 그대로
종전 값**이다(As-Is 지문만 갱신했다 — 이 대비가 변경 범위의 하드 체크다).

### 기준 ③ VTC 선택 — V2와 V3는 구분되지 않는다 → **V3 채택**

12 seed 쌍체 (SC3 ×1.5 · 900초):

| 변형 | As-Is 격추 | 쌍체 Δ격추 | 95% CI |
|---|---|---|---|
| BASE | 64.8 | 38.9 | [34.9, 42.9] |
| V1 (문자만) | 66.8 | 36.9 | [32.3, 41.6] |
| **V2** (VTC 180) | 65.1 | **38.7** | **[34.2, 43.2]** |
| **V3** (VTC 135) | 65.7 | **38.1** | **[33.6, 42.5]** |

CI가 거의 완전히 겹친다. 사전 규칙에 따라 **V3(제안값 90~180)** 를 채택한다.
Δ 상대 이동은 BASE 38.9 → V3 38.1로 **2.1%** — 에스컬레이션 기준(20%) 미만.

### 기준 ② 방향 — **부분 미충족 (숨기지 않는다)**

As-Is 자기쌍체(BASE ↔ V3) 12 seed:

| Δ지표 | 평균 | 95% CI |
|---|---|---|
| Δ격추 | +0.83 | [−3.09, +4.75] |
| Δ누수 | −0.33 | [−4.12, +3.45] |
| Δ중복교전 | **+0.33** | [−1.02, +1.68] |
| Δ협조공백 | +0.33 | [−1.02, +1.68] |
| Δ결심지연 | −1.02 | [−5.48, +3.44] |
| Δ교전 위협 수 | +1.08 | [−3.29, +5.46] |
| Δ요격탄 소모액 | +4.38 | [−10.92, +19.69] |

**7개 지표 전부 CI가 0을 포함한다.** 임무 지표는 유의하게 움직이지 않는다.

예측했던 "중복교전 감소·드롭 감소"는 **부호가 반대**로 나왔다(중복교전 +0.33, 드롭
293→306). 유의하지는 않지만 메커니즘은 설명된다:

```
문자가 빨라짐 → 항적이 방공C2A에 일찍 도착 → 교전이 늘어남
            → 교전현황 메시지도 늘어남 (전송 409 → 436)
            → 1채널·4건 유한 용량 채널의 부하가 증가
```

**한 채널을 빠르게 하면 병목이 다른 채널로 옮겨간다.** 이 모델에서 유한 용량 채널은
교전현황 VTC 하나뿐이라 그 부하가 여기로 몰린다.

### 뚜렷하게 좋아진 것 하나

| 교전현황 채널 (12 seed 합) | BASE | V3 |
|---|---|---|
| 전송 | 409 | 436 |
| **전달** | **42** | **58** |
| 드롭 | 293 | 306 |
| **전달률** | **10.3%** | **13.3%** |

VTC가 빨라진 만큼 같은 창에서 더 많이 전달된다. 드롭 **수**는 늘었지만 전송 자체가
늘어서이고, 드롭**률**은 71.6% → 70.2%로 소폭 개선됐다.

## 결정

```
C2-ENG-STATUS-01  Tri(90,180,270) → Normal(135, σ22.5) · 대표 180 → 135초
C2-CHAT-TRACK-01  Tri(20,45,120)  → Normal(45,  σ7.5)  · 평균 61.7 → 45초
C2-VOICE-COORD-01 Normal(20, σ5)  변경 없음 (ADR-080에서 이미 전환)
```

이로써 카탈로그의 **링크 지연 분포는 전부 정규분포**가 됐다(남은 삼각분포는 사수 pk
기본값의 퇴화형 min=mode=max 하나뿐이며 링크 지연이 아니다).

세 값 모두 **등급 C를 유지한다.** 등급 C끼리의 교체이므로 근거가 강해진 것이 아니고,
바뀐 것은 "분포 형태에 대한 판단"뿐이다. 특히 **문자의 긴 꼬리(최대 120초)를 잘라내는 것이
실제 절차를 더 잘 표현하는지에 대한 근거는 없다.**

## 결과 — 기준선 이동 (열세 번째)

**To-Be 전 케이스 bit-exact 불변 · As-Is만 이동** (ADR-079·080·081과 같은 서명).

| 케이스 | 격추 | 누수 |
|---|---|---|
| sc1\|asis | 19 → **24** | 1 → 1 |
| sc2\|asis | 13 → 13 | 0 → 0 |
| sc3\|asis | 59 → **65** | 112 → **106** |
| **To-Be 3케이스** | **불변** | **불변** |

⚠️ 단일 seed 방향(격추 상승)을 효과로 인용하면 안 된다 — 위 자기쌍체가 말하듯
**유의하지 않다**. 난수 재배열의 몫이 섞여 있다.

  남아 있어 정정했다.
