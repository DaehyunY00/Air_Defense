# ADR-112 — 포대 상태 보고(`batteryStatusReporting`): 결심 C2는 「마지막으로 보고된」 포대 상태로 후보를 가린다

> 본 문서의 모든 수치는 공개자료 기반 **정책연구용 개념값**이며 실제 작전자료가 아니다.

- 날짜: 2026-10-02
- 상태: 채택 (엔진 기본 **OFF** · bit-exact · [지휘 흐름] 화면 기본 **ON**)
- 관련: ADR-111(결심 기록 — 이 지연을 「C2가 본 상태 나이」로 보인다) · ADR-109/110(조기 사수 지정·되먹임 — 지연으로 생긴 오지정을 CANTCO가
  받는다) · ADR-069(센서 보고 톱니 — 같은 규약) · C2-DL-DLY-01 · C2-VOICE-RPT-01
- 플래그: `batteryStatusReporting`(기본 OFF) · 값 `statusReportPeriodSec`(기본 4) · 화면 `?bsr=1&bsrp=4`

## 맥락

ADR-111까지 결심 C2의 후보 평가는 포대의 잔탄·교전 채널·자기 MFR 사격통제 등급을 **지연 0으로 정확히** 읽었다. 실제로는 포대가 상태를
주기적으로 올리고 C2는 마지막으로 받은 상태로 판단한다 — 「어느 포대가 가능한가」를 확인하는 과정 자체가 모델에 없었다(사용자 지적
2026-10-02: "C2 관점에서는 각 포대 중 어떤 포대가 가능한지 확인하는 과정이 있어야 한다. 구조 자체가 있어야 하니 고정값으로 넣자").

## 결정

플래그 ON이면 결심 C2의 후보 평가(`_iadsDecide`의 포대 루프와 승인 계선 필요 판정)가 포대마다 **보고 기준 시각** `asOf`의 상태를 쓴다.

- **보고 구조** — 포대는 `P = statusReportPeriodSec`(기본 4초)마다 상태를 발신하고, 전문은 C2→ECS 하향 계선(`_iadsShortestPath(commander,
  ecs, ['coord','command'])`)의 **대표 지연 합 d**(카탈로그 `comm[mode].delaySec` · 분포가 아닌 대표값 · 난수 없음) 뒤에 닿는다. C2가 t에
  아는 상태 = 발신 시각 `max{kP : kP + d ≤ t}`의 상태. 첫 보고 전(t < d)은 초기 상태. 모든 포대가 같은 위상(kP)으로 보고한다.
- **지연되는 것** — 잔탄·교전 채널(발사·교전 종료·재장전 완료마다 포대가 기록을 남기고 C2는 `asOf` 이전 마지막 기록을 읽는다) · 자기 MFR
  사격통제 등급(`stateChangedAt > asOf`면 아직 모른다 · ADR-070 원격 등급도 같은 규칙) · 기하 모델(`iadsSensorPhysics` OFF)에서는
  사격통제 성립 시각을 `asOf` 기준으로 본다.
- **지연되지 않는 것** — 요격점·요격 창은 C2 자체 계산이라 지연 0. 포대 자신의 발사 전 재검증(`fire-command`)·큐 포대 자체 판단(ADR-104 ②)·
  자위권(ADR-071)은 **실제** 상태. 그래서 C2가 늦은 상태로 지정한 포대는 실제로 못 쏘면 `발사불가`/CANTCO(ADR-110)로 되돌아온다 —
  지연이 만든 오지정이 되먹임으로 흡수되는 구조다.
- **기록** — ADR-111 결심 기록의 후보마다 `age = t − asOf`(초)를 싣고, 화면은 「C2가 본 상태 나이 a~b초」로 적는다.

## 값

[IADS-STATUS-RPT-01] 보고 주기 4초(데이터링크 자동 상태 갱신 개념값 · 등급 C). 계선 지연은 카탈로그를 그대로 쓰므로 **통신계선 시트
(xlsx)로 바뀐다**; 주기는 features/URL 값이다(xlsx 가져오기는 카탈로그만 덮는다 — ADR-108). 분포로 두지 않은 이유: 데이터링크 보고의
나이는 결심 시각이 주기 안 어디에 걸리느냐로 이미 0~P 톱니 분산을 가지며(ADR-069와 같은 규약), 고정값이 xlsx·URL로 바로 고쳐진다.

잡음 안」이며, 체계 효과는 다중 seed 비교로만 말할 수 있다(이 ADR 범위 밖). **효과척도 분석결과서(2026-09-29)는 이 플래그 OFF 조건의
수치다** — 결과서 §조건에 명시.

## 한계

- 보고 위상을 모든 포대가 공유한다(kP). 포대별 위상 분산은 넣지 않았다.
- 상향 계선 지연을 하향 계선 대표값으로 대신한다(카탈로그에 상향 상태 계선이 없다).
- 음성 계선이 끼는 경로(As-Is 일부)는 대표값(수십 초)이 그대로 d가 되어 분포 없이 고정된다.
