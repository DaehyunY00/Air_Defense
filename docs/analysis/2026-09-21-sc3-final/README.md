[분석 PDF](../../../K-JAMDS_분석_방법과_결과.pdf)에 사용한 집계와 용어 설명이다.
SC3만 다루고, 시간대별 중간 실적 비교와 기존 13·14장을 뺐다.

## 실행 범위

기존 SC3에서 1800초까지 생성되는 항적을 고정한 뒤, 새 항적은 추가하지 않고
생성된 항적이 모두 격추 또는 누수로 끝날 때까지 모의했다.
같은 비교 쌍에는 같은 항적과 같은 관측 종료 상한을 적용했다.
종료 상한은 생성된 항적들의 예정 비행 종료 시각 중 가장 늦은 시각이다.
시뮬레이터 화면의 기본 실행시간과 무기·지휘통제 규칙을 바꾸지는 않았다.

- 기준 비교: 2개 배치 × 2개 구조 = 4조건
- 한 조건씩 바꾸기: 16개 설정 × 2개 배치 × 2개 구조 = 64조건
- 반복 비교: 20개 난수 시작값 × 2개 배치 × 2개 구조 = 80조건
- 위협 생성 강도: 5개 강도 × 2개 배치 × 2개 구조 = 20조건

합계는 168개 비교 조건이다. 입력이 완전히 같은 기준값·시작값 29·강도 1의
중복 8조건은 결과를 재사용했다. 실제 완료 실험은 160회이며,
기존 소스의 1800초까지 동작과 정확히 같은지 확인하는 기준 실행 4회가 별도로 있다.

## 누수와 미해결

| 구분 | 뜻 |
|---|---|
| 격추 | 모델이 요격 성공으로 판정해 항적이 종료됨 |
| 누수 | 격추되지 않은 채 모델의 비행 종료까지 도달한 최종 결과 |
| 미해결 | 관측을 멈춘 시점에 격추·누수가 아직 정해지지 않은 상태 |

미해결 항적을 누수로 강제 변경하지 않았다. 모의를 계속해 원래 판정 규칙으로
결과를 얻었으며, 168조건 모두 미해결 0개와 `생성 = 격추 + 누수`를 확인했다.
누수는 실제 지상 명중이나 피해의 확정을 뜻하지 않는다.

## 목적지와 출발점 설정

### 여러 지상 목적지 배정 끄기 (`aim`)

이전 표현은 '지정된 지상표적 사용 끄기'였다. 여러 지상 목적지 중 하나를 배정하는
기능을 끄고, 진입 방향별 기본 목적지로 돌아간다는 뜻이다.
현재 적용 대상은 단거리 탄도탄과 대구경 방사포다.
목적지 주변에 위치를 흩어 놓는 설정은 별도로 유지된다.

### 탄도 위협 출발점 연장 (`lx`)

기존 진입 지점보다 더 먼 가상 출발점에서 시작하도록 비행 경로 앞부분을 추가한다.
거리가 늘어나는 만큼 비행시간도 늘린다. 끄면 기존 진입 지점부터 비행을 모의한다.
실제 발사 위치를 확인한 정보가 아니라 모델의 경로 가정이다.

두 설정은 위협의 목적지·경로·비행시간을 바꾼다. 따라서 설정을 바꾼 결과의 차이를
지휘구조 변화 하나의 효과로 해석하지 않는다.
