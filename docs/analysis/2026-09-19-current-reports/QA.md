## 수행한 검사

- PDF skill의 편집 시작 marker를 최초 작성 직전에 1회 실행했다.
  인수는 `--operation-kind edit --expected-output-count 2 --output-format pdf`였다.
- 일반 분석은 182개 셀과 별도 탐침 1개를 새로 실행했다. 2개 계산 worker를 사용했고 분석 셀 실행은
  383.756초였다. 생성 보존식, 누수 원인 합계, 같은 seed의 모드별 생성 수 검사에 모두 통과했다.
- C2 네 실행과 파서 self-test를 수행했다. 동일 분기의 시간 연결, 자식 명령의 계보,
  동일 발사의 BDA, 기록 절단 처리, 통신 상태와 정식 노드 필터 검사를 통과했다.
  전체 206개 실제 발사 항적의 최초 발사 시간을 연결했고 네 실행의 기록 절단은 없었다.
- 일반/C2 기준값·코드 해시·쌍대 통계의 독립 검산은 `integration-validation.md`에 기록했다.
- 설치된 Playwright와 Chrome으로 폰트 로딩을 기다린 뒤 인쇄했다. 두 HTML의 22개 페이지에서
  JavaScript 오류, 가로 넘침, 본문/꼬리말 겹침은 모두 0건이다(`render-qa.json`).
- Poppler `pdfinfo`로 10/12페이지와 A4를 확인했다. `pdftotext -layout` 결과에서 22개 페이지의
  내용과 페이지 번호를 확인했고, 대체 문자 및 미해결 `NaN`/`undefined` 값은 없었다.
- Poppler 110 dpi PNG를 전 페이지 열어 검토했다. 제목·표·한글·수식·카드·화살표·주석·꼬리말의
  가독성과 잘림/겹침 여부를 확인했다. 최종 시각 검토에서 남은 결함은 없었다.

## 검토 중 보완한 표현과 배치

- 과거 178회·15조건 안내를 실제 182개 분석 셀·16조건으로 수정했다.
- 시간 지표를 실제 수집 경계에 맞춰 생성/탐지에서 최초 실제 발사까지로 고쳤다.
  서로 다른 분기·발사의 사건을 결합하지 않고 관측 분모와 종료 미해결을 함께 제시했다.
- 역할 문맥·후보 근거를 실제 노드·통신에 넣지 않았고, 무근거한 초/노드 효율비와 고정 우열
  결론을 제거했다. 단일 seed와 20개 쌍대 seed의 근거 범위를 구분했다.
- C2 초안의 사례 카드 7–10쪽은 꼬리말과 겹쳐 자동 검사가 인쇄를 차단했다. 사건 표의 불필요한
  줄바꿈과 간선 간격을 조정해 모든 사건과 글꼴 크기를 유지하며 해결했다.
- C2 간선 그림의 긴 한글 이름은 실제 표시 폭에 맞춰 명시적으로 축약했다. 전체 이름/정식 ID는
  HTML title과 분석 JSON에 남겼으며 PDF에도 축약 안내를 넣었다. 최종 6–10쪽을 다시 검토했다.
  마지막 수정 전후 PNG 해시 비교에서 이 다섯 쪽만 바뀌었고, 앞서 검토한 나머지 17쪽은 같았다.

## 증거와 재현

`pdf-qa.json`에 최종 PDF SHA-256, 페이지별 텍스트 길이, PNG 경로와 SHA-256을 보존한다.
임시 이미지·추출 텍스트·pdfinfo는 `/tmp/kjamds-pdf-qa/`에 있으며 Git 산출물이 아니다.
다음 명령으로 같은 입력 HTML의 인쇄·기계 검사를 다시 수행할 수 있다.

```bash
node docs/analysis/2026-09-19-current-reports/render-reports.mjs
node docs/analysis/2026-09-19-current-reports/verify-pdfs.mjs /tmp/kjamds-pdf-qa
```

시각 검토는 자동 검사와 별도 단계다. HTML을 변경했다면 새 PNG를 다시 확인해야 한다.
이번 검증은 보고서의 재현·계정·기록·표현 검증이며 실제 군사 운용 성능의 검증이 아니다.
문서 갱신 때문에 전체 엔진 52개 테스트를 재실행했다는 의미도 아니다.
