## 수행한 검사

- 일반 분석 182개 셀과 탐침 1개, C2 기록 4개를 1800초로 새로 실행했다. 2개 계산 worker,
  분석 셀 1,594.946초. 엔진·어댑터 해시와 seed 집합이 600초판과 같음을 생성기가 검사한다.
- C2 파서 self-test 통과: 동일 분기의 시간 연결, 자식 명령의 계보, 동일 발사의 BDA, 기록 절단 처리,
  통신 상태와 정식 노드 필터.
- `report-gen.mjs`의 교차 검산 통과: 소스 해시 일치, 네 기준 실행의 계정 일치, 발사 항적 수 일치,
  계보 제외 2건 = 기록된 사유의 합, 제외가 없는 두 실행의 시간 평균 일치.
- Playwright와 Chrome으로 폰트 로딩을 기다린 뒤 인쇄했다. 20개 페이지에서 JavaScript 오류,
  가로 넘침, 본문/꼬리말 겹침은 모두 0건이다(`render-qa.json`).
- Poppler `pdfinfo`로 20페이지를 확인했다. `pdftotext -layout` 결과에서 20개 페이지의 내용과
  페이지 번호를 확인했고, 대체 문자 및 미해결 `NaN`/`undefined` 값은 없었다.
- Poppler 110 dpi PNG를 열어 제목·표·한글·카드·화살표·주석·꼬리말의 잘림/겹침을 확인했다.
  1800초 재작성에서는 수치·구성이 바뀐 1·4~13·15·18~20쪽을 다시 열어 보았고, 틀이 그대로인

## 증거와 재현

`pdf-qa.json`에 최종 PDF SHA-256, 페이지별 텍스트 길이, PNG 경로와 SHA-256을 보존한다.
임시 이미지·추출 텍스트·pdfinfo는 `/tmp/kjamds-pdf-qa/`에 있으며 Git 산출물이 아니다.

```bash
node docs/analysis/2026-09-19-current-reports/render-reports.mjs
node docs/analysis/2026-09-19-current-reports/verify-pdfs.mjs /tmp/kjamds-pdf-qa
```

시각 검토는 자동 검사와 별도 단계다. HTML을 변경했다면 새 PNG를 다시 확인해야 한다.
