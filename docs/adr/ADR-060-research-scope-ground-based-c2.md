# ADR-060 — 연구 범위 명시 축소: 지상배치 방공체계(지대공) C2

## 맥락

legacy 배치에만 존재하는 자산 5종 — 전투기(KF-16·F-15K·KF-21), 이지스 SM-2(동·서해),
E-737 조기경보기, 이지스 레이더, 광학감시(ADC2A-W) — 는 고해상도 타입 레지스트리에 대응
타입이 없다(전부 이동 플랫폼: 고도·위치가 시간의 함수). legacy·compat을 폐기(Phase 6)하면
이 전력이 모델에서 완전히 사라진다. Phase 5(폐기 조건 확인)는 두 갈래 중 택일을 요구한다.

## 선택지

- **(a) 이동 플랫폼 타입을 IADS 레지스트리에 추가** — 모델 충실성의 정공법. 그러나
  전투기 초계·요격 운동학, 함정 기동, 공중 조기경보 궤도는 각각 고도·위치가 시간의 함수인
  새 운동학 계층을 요구한다 — 위협 운동학(§3-1, 현재 미충족)조차 개념 축선인 상태에서
  아군 플랫폼 운동학을 먼저 만드는 것은 우선순위 역전이며, 비용이 크고 근거 수치(요격기
  초계 패턴·CAP 스테이션 등)는 등급 C를 벗어나기 어렵다.
- **(b) 연구 범위를 "지상배치 방공체계(지대공) C2"로 명시 축소** — 채택. 저렴하고 정직하다.
  단 SC1의 요격기 운용 대조가 범위 밖이 되고, "요격기·해상 자산 미포함"을 상시 표출해야 한다.

## 결정

**(b)를 채택한다.** 결정적 근거:

1. **이미 사실이다.** 주 분석 배치(LEGACY_HIRES)와 FULL은 2026-07-19 이식(ADR-054) 이래
   이 5종 없이 운용되어 왔고, 실험보고서·모의논리서가 그 상태의 수치를 보고해 왔다.
   (b)는 현상의 명문화이지 새로운 축소가 아니다.
2. **연구 질문과의 정합.** KJADS 3대 문제상황(경계 책임공백·무인기·복합 포화)의 원인 구조는
   지상배치 C2 계통(KAMDOC/MCRC/군단 AOC/ICC/ECS)에 있다. 요격기·해상 자산은 legacy에서도
   보조 전력이었다.
3. **(a)의 비용이 §6의 다른 미충족(위협 운동)보다 후순위일 수 없다** — 같은 운동학 계층을
   요구하는데, 위협 운동이 먼저다.

## 구성 (Phase 6에서 이행할 작업 목록 — 본 ADR 시점 코드 무변경)

1. 디스클레이머(README 최상단·index.html·모의논리서·실험보고서·사용자 가이드)에
   **"본 모델은 지상배치 방공체계 C2에 한정하며 요격기·해상 자산을 포함하지 않는다"** 상시 표출.
2. SC1 서술에서 요격기 관련 문구 제거·재정의 확인.
3. `docs/compat-retirement-readiness.md`의 판정과 연동 — legacy 삭제 커밋에 본 ADR 참조.

## 검증

Phase 6 수용 기준에 "디스클레이머 표출 어서션"(constraints.test.js 확장)을 포함시킨다.
본 Phase에서는 코드 무변경이므로 검증 항목 없음 — 판정표(`compat-retirement-readiness.md`)가
근거 문서다.

## 결론 영향

G6 4종 무영향(코드 무변경). 연구 보고 문언에는 영향: 이후 모든 결론 인용에 "지상배치
방공체계 C2 범위" 한정이 붙는다.

## 되돌리는 법

(a)로 전환하려면 이 ADR을 대체하는 신규 ADR로 이동 플랫폼 타입 설계를 확정하고,
`system-types.js`에 타입 추가 + 위협/아군 공용 운동학 계층을 신설한다. 본 ADR은 코드가
없으므로 문서 대체만으로 되돌려진다.

## 한계

1. SC1의 "요격기 대 지대공 혼합 운용" 질문은 이 저장소로 답할 수 없게 된다(범위 밖 명시).
2. 해상 탄도탄 방어(이지스)와의 합동 C2 질문도 범위 밖 — 후속 연구 과제.
3. (b)는 legacy·compat이 존재하는 동안에는 "legacy 경로에만 남은 전력"이라는 비대칭을
   유지한다 — legacy와 고해상도의 절대값 비교 금지 사유가 Phase 6까지 지속된다.
