# ADR-100 — C2 상태·설정·관측 정합성

- 날짜: 2026-09-16
- 상태: 적용
- 배경: `12d14e0` 기준 지휘흐름 단일본 C2 검토

## 문제와 결정

1. **기본 설정 타입**: `par`의 기본 숫자 `1`이 카탈로그의 `=== true` 검사에서 제외되어 화면 ON과
   실제 IAOC 처리시간이 달랐다. 기본값과 URL 입력을 동일한 함수에서 타입 정규화한다.
   기본 URL, 빈 값, 기본값을 명시한 URL의 기능 설정이 같아야 한다.
2. **계통별 실패 격리**: native C2의 협조 회신·명령 발령·ICC 중계 드롭을 해당 계통의 실패로
   처리한다. 기존 승인/명령의 종료와 재시도 규칙을 유지하며 다른 계통의 공통 위협 상태를
   중단시키지 않는다. 명령 발령의 용량·기한 실패는 앞서 공유한 할당의 해제 상태도 통보한다.
3. **상태정보 시간·순서**: 상태의 유효기간은 생성시각 기준이다. 노후 상태 및 이전 갱신을
   다시 채택하지 않는다. 같은 생성시각의 갱신은 발신자별 순번으로 비교한다. 채택 여부와
   무관하게 메시지 수신·채널 해제·후속 대기 메시지의 전송 계정은 유지한다.
4. **명령 발령자·계보**: ICC 재배정은 실제 발령자 `issuedByC2Id`와 부모 `parentDirectiveId`를
   기록한다. 기존 통제 주체 `commander`는 유지하여 감사 메타데이터 변경이 선정·경로 규칙을
   바꾸지 않게 한다. 생성 및 수명주기 이벤트에도 두 필드를 전달한다.
5. **전수/표본 구분**: 상태줄은 전체 생성·격추·누수·종료 미해결과 상세 기록 수를 함께 표시한다.
   항적 기록 절삭과 흐름 기록 절삭은 별도로 알린다. 항적 목록·지도·복수 사수 집계가 상세
   기록 표본에 한정되면 그 범위를 표시한다.
6. **검증 계약**: 결과의 우열·특정 병목·특정 seed의 포화를 정상 동작의 조건으로 고정하지
   않는다. 제대 계층 회귀는 책임 배정과 통보 큐의 독립성을 검사하며, 강제 포화 조건에서
   도메인 통보 드롭이 IAOC 처리에 전파되지 않는지 확인한다.

## 범위

기존 도메인 통보는 완료 결과가 IAOC 결심에 영향을 주지 않는 비차단 통보다. README와
엔진 설명을 실제 구현에 맞췄다. 도메인별 승인·거부권을 추가했다는 의미가 아니다.

식별 불확실성, 위임 범위·회수·단절 절차, 인간 판단시간 분포의 현실 타당성은 모델 요구사항과
근거 검증이 필요한 별도 항목이다. 이번 수정은 해당 개념값이나 지휘관계 가정을 새로 만들지
않는다. seed29는 재현용 예시이며 변경된 기본 조건의 대표성을 주장하지 않는다.

## 검증

- `tests/c2-state-integrity.test.mjs`: 신규 작업별 포화·기한 실패, 타 계통 생존, 할당 해제 통보,
  상태 노후·역순·동시각·중복 수신, 채널 계정, ICC 발령자/부모 명령을 실제 처리 경계에서 검사.
- `tests/command-flow-config.test.mjs`: 실제 HTML의 파서·기능 설정·표시 함수를 실행하여
  기본/명시 URL 동치와 카탈로그 적용을 확인. 관측 상한이 전체 결과를 바꾸지 않는지도 확인.
- `tests/c2-echelon-hierarchy.test.mjs`: 낡은 고정 성과값 대신 책임 배정과 분리된 통보 부하의
  계약을 검증. 과거 포화·성과 기대값이 ADR-088 이후 용량 변경으로 무효화된 문제를 정정.
- `engine`·`mc`·`transition`·`legacy-hires-deployment` 회귀: 모드 우열·지배 원인·민감도 순위를
  통과 조건에서 제외하고 기존 실행의 병목 증거·분모·계정을 대사한다. 통제 입력으로 IAOC
  병목, 양·음·0 쌍대 차이와 CI, 증가·감소·무효과 민감도, 전환점 미발생·빈 구간을 검증한다.
  기존 고정 조건의 수치 지문 회귀는 별도로 유지한다.
- `engagement-state-unification`·`decision-audit`·`shadow-eval`·`native-wta`의 기존 실패는
  수정 전 `12d14e0` 엔진·스키마에서도 재현했다. 오래된 지문을 새 값으로 덮어쓰지 않고
  상태 소비 계약, 기본/명시 토글 동치, 계측 전용 필드 이외 전체 결과·이벤트·RNG 불변,
  비용항 적용 범위 및 통제 후보의 순위 계약을 검사한다. 그림자 평가의 모드 우열은 관측으로
  남기며 놓침률의 최초 결심·마감 경계·미결심·빈 분모를 통제 입력으로 확인한다.
- `approval-authority`의 오래된 MCRC 8서버 기대값은 ADR-088의 10서버로 정정하고,
  결심시간 동일화가 서버 수를 바꾸지 않는지 확인한다.
- 공통 엔진·커널을 포함하는 앱 단일본과 지휘흐름 단일본을 모두 재생성한다.

수정 전 보고서와 원시 관측은 `docs/analysis/2026-09-16-command-flow-c2-review/`에 보존한다.
실행별 격추·누수의 변화는 수정 영향을 확인하는 자료이며, 단일 seed 차이를 구조 효과의
추정치로 사용하지 않는다.
